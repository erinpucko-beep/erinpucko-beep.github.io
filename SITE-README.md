# Erin Pucko — author website

A free, single-page static author website. No build process, paid services, or backend required.

## Preview
Open `index.html` in any browser.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with the professional email address you want public. Alternatively, remove the email button until ready.
2. Replace the author photo placeholder in the About section with your actual photograph. Suggested: a 4:5 portrait named `erin-pucko.jpg` in this folder. Replace `<div class="portrait"> ... </div>` with `<img src="erin-pucko.jpg" alt="Erin Pucko" style="width:100%;aspect-ratio:4/5;object-fit:cover">`.
3. Review all biography and novel text for accuracy and comfort before publishing.
4. The Union Made cover shown is a **decorative placeholder**, not a published cover.

## Free hosting with GitHub Pages
1. Create a free GitHub account at github.com.
2. Create a **public** repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your GitHub username).
3. Upload `index.html` (and your photo file if applicable) to the repository's root.
4. Under **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Visit `https://YOURUSERNAME.github.io/` after deployment completes.

GitHub Pages is available for public repositories on GitHub Free. You can later attach a custom domain if desired (domain registration usually costs money).

## Notes
- Google Fonts are used for typography; fallback fonts display if unavailable.
- All design decorations are created with HTML/CSS; no third-party stock photos are used.
- There is no newsletter, analytics, tracking, or contact form.
